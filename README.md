# Anurag Singh — Engineering Portfolio

A local, single-page portfolio for engineering, embedded, IoT and software opportunities. It uses plain HTML, CSS and JavaScript, with no framework or build step.

## Open locally

Open `index.html` in a browser. This portfolio is local and unpublished.

## Edit content

- Visible section copy and cards are in `index.html`.
- Expanded project details and repository links are in `script.js`.
- Replace or resolve each `TODO` only after confirming the source information.
- Retain upstream attribution for the forked LPG repository and describe it as an educational prototype, not certified safety equipment.

## Add achievements over time

Open the “Update this portfolio with a new achievement” panel near the bottom. Add the title, category, date, short story and optional image; then choose **Add to preview**. The change is stored in this browser. Choose **Download update file** to get `achievements.json`, then replace the existing file in this folder with it. Upload the updated folder to GitHub Pages to publish the new achievement. You can use **Load saved updates** to preview an existing JSON file before changing it.

This site is static, so it cannot accept a file upload directly into the public website or save edits to GitHub. You keep control: prepare the achievement in the site, download the update file, then upload the changed site to your GitHub repository. Keep uploaded images under 1.5 MB.

The opening visual now rotates through the original electronics illustration and locally stored project photos. Use the arrows or dots to navigate, and the pause button to stop autoplay. The slideshow pauses on hover and focus and stays still when reduced motion is enabled.

## Images

- Project and certificate photos come from the supplied LinkedIn material and are saved locally in `assets/`.
- `assets/engineering-atmosphere.png` is an original decorative visual created for this portfolio. It is labelled as decorative and is not presented as project evidence.
- Video cards open LinkedIn because a local playable video file was not available.
- No remote images are hotlinked.

## Before publishing

- Add a CV PDF and wire it to a download button.
- Verify academic results, internship dates, remaining credentials and individual project contributions.
- Add the Laser project source/demo and complete Class X details.
- Review the contact information before publishing.

## Free deployment

For GitHub Pages, place this folder in a GitHub repository and enable Pages from the main branch and root folder. For Netlify, drag this folder into the manual deploy page or connect the repository. No build command is required.
